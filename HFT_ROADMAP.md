# HFT & Low-Latency C++ — Roadmap

## Что такое HFT (High-Frequency Trading)

Алгоритмическая торговля на бирже, где сделки совершаются за микросекунды.
Программы автоматически покупают и продают акции, валюту, фьючерсы — быстрее, чем любой человек.
Прибыль с одной сделки крошечная, но за счёт миллионов сделок в день набегает серьёзный доход.

## Почему C++

- Каждая наносекунда имеет значение — кто быстрее, тот и заработал
- Прямой контроль над памятью, CPU кэшами, сетевым стеком
- Никакой garbage collection, никаких лишних аллокаций
- Lock-free структуры, kernel bypass, FPGA

## Типичные задачи C++ разработчика в HFT

- Парсинг биржевых протоколов (FIX, ITCH) с минимальной задержкой
- Order book — книга заявок в памяти с обновлением за наносекунды
- Сетевой стек в обход ядра ОС (DPDK, Solarflare OpenOnload)
- Оптимизация под конкретный CPU (cache lines, branch prediction, SIMD)

## Зарплаты

- Junior: $150-250k/год
- Senior: $400-700k+/год
- Топовые фирмы: Jane Street, Citadel, Two Sigma, Jump Trading, Tower Research

## Минусы

- Высокий порог входа
- Большинство фирм в Нью-Йорке, Лондоне, Чикаго
- Жёсткие собеседования (алгоритмы + системное программирование + математика)
- Стрессовая среда

## Практические проекты для набора опыта

### 1. Matching Engine (движок сопоставления заявок)
Ядро биржи — сопоставляет buy/sell заявки.
- Order book с приоритетом по цене и времени
- Lock-free очереди для входящих заявок
- Цель: обработка заявки < 1 микросекунды

### 2. In-memory Key-Value Store (мини-Redis)
- Lock-free hash map
- io_uring для асинхронной сети
- Zero-copy буферы
- RESP-протокол для совместимости с redis-cli

### 3. Market Data Feed Handler
- Парсинг потока биржевых данных (Binance WebSocket как источник)
- Быстрая десериализация JSON/binary
- Ring buffer для хранения последних тиков
- Цель: обработка сообщения < 500 наносекунд

### 4. Low-Latency Logger
- Асинхронный логгер без блокировок
- SPSC (single-producer single-consumer) ring buffer
- Форматирование в фоновом потоке
- Цель: вызов log() < 50 наносекунд

### 5. Custom Memory Allocator
- Pool allocator для объектов фиксированного размера
- Arena allocator для batch-обработки
- Убрать malloc/free из горячего пути
- Цель: аллокация < 10 наносекунд

## Ключевые навыки для изучения

### Low-Latency C++
- Memory model (std::atomic, memory_order)
- Lock-free структуры данных (queue, stack, hash map)
- Cache-friendly структуры (struct of arrays, padding, alignment)
- SIMD (SSE, AVX2, AVX-512)
- Compile-time вычисления (constexpr, templates)
- Branch prediction hints ([[likely]], [[unlikely]])
- Placement new, custom allocators

### Системное программирование
- io_uring — асинхронный I/O в Linux
- DPDK — сеть в обход ядра
- Huge pages — уменьшение TLB misses
- CPU pinning — привязка потоков к ядрам
- NUMA awareness

### Инструменты профилирования
- `perf stat` — счётчики CPU (cache misses, branch mispredictions)
- `perf record` + flamegraph — визуализация hotspots
- Intel VTune — глубокий профайлинг
- `google/benchmark` — микробенчмарки
- Valgrind / cachegrind — анализ кэша
- Address/Thread Sanitizers — поиск багов

### Финансовые рынки (основы)
- Как работает order book (bid/ask, spread)
- Типы ордеров (market, limit, stop)
- Протоколы: FIX, ITCH, OUCH
- Стратегии: market making, arbitrage, statistical arbitrage

## Бизнес-направления на основе C++ + AI + сетевых навыков

### Уровень 1 — Данные и автоматизация ($1-10K/мес)

#### SERP API сервис (уже реализован)
- Скрейпинг поисковиков (Google, Bing, Yandex, DuckDuckGo) через residential/mobile прокси
- TLS fingerprint имитация через curl_cffi
- FastAPI сервер, парсинг HTML → JSON
- Себестоимость: ~$10/мес (прокси Decodo)
- Аналоги берут $50-100/мес с клиентов за то же самое

#### Ферма телефонов — универсальная инфраструктура
- Телефоны как мобильные прокси (каждый со своей SIM-картой, свой IP)
- Эмуляторы на сервере выполняют задачи через прокси телефонов
- Схема: 1 сервер (20 эмуляторов) → 10 телефонов (модемы) → действия в соцсетях
- Телефон не выполняет задачи — просто пропускает трафик как VPN
- Безопасная пропорция: 3-5 аккаунтов на 1 мобильный IP
- Ротация IP: вкл/выкл авиарежима через adb → новый IP бесплатно
- Старт: 3-5 б/у Xiaomi Redmi + SIM-карты разных операторов (Beeline, Kcell, Tele2)

#### Продажа мобильных прокси
- Мобильные IP самые ценные — почти не банятся
- Казахстанские IP — редкость, конкуренции мало
- Цена: $50-150/мес за один прокси
- Клиенты: арбитражники, SMM-щики, скрейперы
- Где искать клиентов: Lolz/Zelenka, BlackHatWorld, Telegram чаты по арбитражу
- Софт: Proxidize / iProxy или свой (Python + adb)

#### SMM панель / Накрутка
- Автоматизация лайков, подписок, комментариев в Instagram/TikTok/Telegram
- ИИ-комментарии через Claude API — уникальные, с контекстом поста (~$1 за 1000 штук)
- Управление эмуляторами через uiautomator2 + adb
- Стек: FastAPI + Redis/Celery + PostgreSQL + uiautomator2
- Рынок КЗ пустой — локальных SMM-панелей нет
- Клиенты: инста-магазины, блогеры, рестораны, салоны — оплата через Kaspi
- Доход: 20-30 клиентов × 15K тг = 300-450K тг/мес

#### Парсинг и данные
- Мониторинг цен (Kaspi, Wildberries, Ozon) — $500-3000/мес
- Сбор лидов/контактов из 2GIS, Instagram — $500-2000/мес
- Агрегация вакансий/объявлений — $300-1000/мес

## Безопасность — что изучать

### Веб-уязвимости (OWASP Top 10)
- **SQL injection** — как ломают базы данных
- **XSS** — как внедряют код в сайты
- **CSRF** — подделка запросов от имени пользователя
- **SSRF** — атака на внутренние сервисы через сервер
- **IDOR** — доступ к чужим данным через подмену ID

### Сетевые атаки
- **MITM** — перехват трафика между клиентом и сервером
- **DDoS** — перегрузка сервера запросами
- **DNS spoofing** — подмена DNS ответов
- **ARP poisoning** — перехват трафика в локальной сети

### Продвинутое
- **Reverse engineering** — разбор чужого кода, протоколов, бинарников
- **Cryptography** — как работает шифрование изнутри (AES, RSA, ECDSA)
- **Binary exploitation** — переполнение буфера, ROP chains
- **Kernel exploitation** — уязвимости на уровне ОС

### Где учить (практика)
- **TryHackMe** — с нуля, пошагово, в браузере
- **HackTheBox** — реальные машины для взлома
- **PortSwigger Web Academy** — веб-уязвимости, бесплатно
- **CTF соревнования** — задачи на взлом, лучшая практика
- **OverTheWire (Bandit)** — основы Linux и безопасности

## 5 уровней защиты — как строить идеальную безопасность

### Уровень 1: Сетевой
- Anycast сеть — распределение трафика по серверам мира
- Rate limiting — ограничение запросов с одного IP
- BGP blackholing — сброс мусорного трафика на уровне маршрутизации

### Уровень 2: Транспортный (TLS)
- Проверка TLS fingerprint
- Сравнение поведения TLS handshake с реальной статистикой браузеров
- Детект curl_cffi по микроотличиям в порядке extensions и timing

### Уровень 3: Приложение (браузер)
- Детект headless браузеров (navigator.webdriver, плагины, canvas/WebGL)
- JavaScript challenges
- Поведение event loop

### Уровень 4: Поведенческий (ML)
- ML-модель на паттернах поведения пользователя
- Анализ движения мыши (ускорение, инерция)
- Распределение времени между действиями (боты = равномерный рандом, люди = нет)

### Уровень 5: Бизнес-логика
- Граф связей между аккаунтами
- ML кластеризация для выявления ферм
- Анализ паттернов активности аккаунтов

**Cloudflare работает только на уровнях 1-3.** Уровни 4-5 не закрыты как сервис — это возможность для нового продукта.

## Поисковые движки — как устроены

### Как работает Google
- Googlebot краулит веб → извлекает текст → строит инвертированный индекс
- Хранит индекс + метаданные (title, URL, сниппет), НЕ полные копии страниц
- Индексирует ~50-60 млрд страниц из ~200+ млрд (25-30% веба)
- Ранжирование: PageRank, BERT, MUM

### Инвертированный индекс
```
"казахстан" → [doc42, doc158, doc903, ...]
"столица"   → [doc42, doc67, doc201, ...]
```

### Размер индекса по масштабу
- 1 млн страниц: ~10 GB диск, ~8 GB RAM → один VPS за $20-40/мес
- 100 млн страниц: ~80 GB SSD, ~32 GB RAM → $100-200/мес
- 1 млрд страниц: ~5-10 TB → шардинг по серверам

### Горячая/холодная архитектура
- В RAM: словарь терминов + часто запрашиваемые данные
- На SSD: остальные posting lists (задержка ~0.1мс, пользователь не заметит)
- 10% данных обслуживают 90% запросов

### Открытые индексы
- Common Crawl — бесплатный архив ~3 млрд страниц
- Brave Search начинали с Common Crawl + свой краулер

```

    ↓
```
